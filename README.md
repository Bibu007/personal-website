## About

A personal portfolio website built to showcase my projects, technical skills, and journey as a web developer.

The website serves as a central place to explore my work, learn more about my background, and find ways to connect with me.

This project focuses on building a modern, responsive, and interactive user interface using React, with an emphasis on component reusability, CSS animations, responsive layouts, and user experience.

## Features

- Personal introduction and landing section
- About section highlighting my background and development journey
- Showcase of personal projects with descriptions and links
- Display of technical skills and technologies
- Interactive navigation between sections
- Animated UI elements and scroll-based effects
- Responsive layouts for different screen sizes
- Social media and GitHub profile links
- Contact information

## Technologies Used

- JavaScript (ES6+)
- React
- HTML5
- CSS3
- CSS Modules
- Vite
- npm

## What I Learned

While building this project, I gained experience with:

- Building reusable and modular components using React.
- Organizing application structure using component-based architecture.
- Managing component state and handling user interactions.
- Creating responsive layouts using CSS Grid and Flexbox.
- Implementing CSS animations and transitions.
- Creating scroll-based animations and interactive UI effects.
- Using CSS Modules to scope styles to individual components.
- Working with responsive typography and layouts.
- Improving accessibility and user experience.
- Structuring a portfolio to effectively showcase projects and technical skills.
- Using Vite for development and production builds.
- Deploying a React application using Vercel.
